# i3 — Window Manager

i3 is a tiling window manager: every window snaps into a rectangle that
neighbours other windows, no overlapping unless you explicitly mark a window
*floating*. The window layout is the application — keyboard-driven, mouse
optional.

**Config:** `~/.config/i3/config` (deployed from `config/i3/config`)
**Reload after edits:** `Mod+Shift+c` (in-place) or `Mod+Shift+r` (full restart)

`Mod` in this dotfiles repo is bound to **Super** (the Windows key).

---

## Launching applications

| Keys             | Action                                       |
|------------------|----------------------------------------------|
| `Mod+Return`     | Open Alacritty terminal                      |
| `Mod+d`          | rofi launcher (`drun` mode — installed apps) |
| `Mod+Tab`        | rofi window switcher                         |
| `Mod+e`          | Thunar file manager                          |
| `Mod+b`          | Firefox (`firefox-esr` on Debian)            |

Anything else: `Mod+d`, type the app name, hit Enter.

To switch the Mod+b binding to a different browser, edit
`~/.config/i3/config` (search for `firefox-esr`) and reload with
`Mod+Shift+c`. Common alternatives:
- `mullvad-browser` — Tor-style hardened Firefox, paired with the
  installed Mullvad VPN.
- `chromium` — install via `sudo apt install chromium`.

## Focus and movement

i3 is fully keyboard-navigable. **h/j/k/l = left/down/up/right** (vim convention).

| Keys                    | Action                              |
|-------------------------|-------------------------------------|
| `Mod+h/j/k/l`           | Focus window in that direction      |
| `Mod+Arrow`             | Same, with arrow keys               |
| `Mod+Shift+h/j/k/l`     | Move the focused window             |
| `Mod+Shift+Arrow`       | Same, with arrow keys               |
| `Mod+a`                 | Focus parent container              |
| `Mod+space`             | Toggle focus between tiled/floating |

---

## Splits and layout

When you open a new window, it splits the current container. You control the
split direction first, then layout style:

| Keys             | Action                                       |
|------------------|----------------------------------------------|
| `Mod+\`          | Next window splits horizontally (side-by-side) |
| `Mod+-`          | Next window splits vertically (stacked)        |
| `Mod+s`          | Stacking layout (titlebars only)               |
| `Mod+w`          | Tabbed layout                                  |
| `Mod+t`          | Toggle split orientation                       |
| `Mod+f`          | Toggle fullscreen                              |
| `Mod+Shift+space`| Toggle current window floating                 |

## Mouse — move and resize

The dotfiles enable both modifier-drag and titlebar-drag, so you can
move/resize windows without keyboard if you prefer:

| Mouse + key combo                | Action                                      |
|----------------------------------|---------------------------------------------|
| `Mod` + **left-drag**            | Move the window (floats it if tiled)        |
| `Mod` + **right-drag**           | Resize from the nearest corner              |
| **Click & hold a titlebar** + drag | Move/swap a tiled window (i3 ≥ 4.21)      |

Drop a tiled window on:
- an existing tile → swap layouts
- an empty area    → start a new container at that spot

The two i3 directives that enable this are at the top of `~/.config/i3/config`:

```
floating_modifier $mod                 # $mod+drag = move/resize
tiling_drag modifier titlebar          # tiled windows draggable too
```

For keyboard-only resize, see the next section.

## Resize mode

Press `Mod+r`. Now h/j/k/l (or arrow keys) resize the focused window. Press
`Esc`, `Return`, or `Mod+r` again to leave the mode.

| In resize mode | Action            |
|----------------|-------------------|
| `h` / `Left`   | Shrink width      |
| `j` / `Down`   | Grow height       |
| `k` / `Up`     | Shrink height     |
| `l` / `Right`  | Grow width        |
| `Esc` / `Ret.` | Exit resize mode  |

## Workspaces

Ten workspaces (`1` through `10`, the latter on `Mod+0`).

| Keys                  | Action                                  |
|-----------------------|-----------------------------------------|
| `Mod+1..9, Mod+0`     | Switch to workspace                     |
| `Mod+Shift+1..0`      | Move focused window to workspace        |
| `Mod+period`          | Next workspace                          |
| `Mod+comma`           | Previous workspace                      |

## Screenshots

| Keys              | Action                                        |
|-------------------|-----------------------------------------------|
| `Print`           | Full-screen screenshot → `~/Pictures/`        |
| `Mod+Print`       | Region screenshot (drag to select)            |

Files are saved as `~/Pictures/screenshot-YYYY-MM-DD_HH-MM-SS.png`
(date + underscore + time, all dash-separated for sortability).

`scrot` ships with `imagemagick` so you can chain conversions:
```bash
# Same shortcut but copy to clipboard instead of disk
scrot -s 'screenshot.png' -e 'xclip -selection clipboard -t image/png -i $f && rm $f'
```

## Media keys

Both the standard XF86 media row (laptops, Bluetooth headsets) and a
Mod+F-row fallback for desktops without media keys are wired up. Each
press emits a dunst notification with the current state.

### Volume

| Keys                  | Action                            |
|-----------------------|-----------------------------------|
| `XF86AudioRaiseVolume`| Volume up 5%                      |
| `XF86AudioLowerVolume`| Volume down 5%                    |
| `XF86AudioMute`       | Toggle mute                       |
| `XF86AudioMicMute`    | Toggle microphone mute            |
| `Mod+F12`             | Volume up (fallback)              |
| `Mod+F11`             | Volume down (fallback)            |
| `Mod+m`               | Mute toggle (fallback)            |

### Playback

Works with any MPRIS-compatible player: Spotify, mpv, Firefox HTML5
audio, VLC, browsers playing music, etc.

| Keys              | Action                                |
|-------------------|---------------------------------------|
| `XF86AudioPlay`   | Play/pause toggle                     |
| `XF86AudioPause`  | Play/pause toggle                     |
| `XF86AudioNext`   | Next track                            |
| `XF86AudioPrev`   | Previous track                        |
| `XF86AudioStop`   | Stop                                  |
| `Mod+F9`          | Play/pause (fallback)                 |
| `Mod+F10`         | Next track (fallback)                 |
| `Mod+F8`          | Previous track (fallback)             |

The bindings call into two helpers:
- `~/.config/i3/scripts/volume.sh` — `pactl` wrapper with progress-bar notification
- `~/.config/i3/scripts/media.sh`  — `playerctl` wrapper showing current track

You can call them directly from a shell to test or to script other
keybinds. See [`system.md`](system.md) for the underlying tools.

## Brightness keys

Wired directly to `brightnessctl` — no helper script, since brightness
adjustment is fast enough that the dunst notification overhead isn't
worth it. Step size is 5%; edit `~/.config/i3/config` to change.

| Keys                       | Action                  |
|----------------------------|-------------------------|
| `XF86MonBrightnessUp`      | Brightness +5%          |
| `XF86MonBrightnessDown`    | Brightness -5%          |

On most ThinkPads the keys are `Fn+F5` / `Fn+F6` (older) or just `F5` /
`F6` (newer with the function-row swap). Desktops without dedicated
brightness keys can ignore — the binding is harmless.

## Network keys

Three different UIs to NetworkManager (described in detail in
[`system.md`](system.md#network-networkmanager--polybar-wlaneth)):

| Keys                       | Action                                            |
|----------------------------|---------------------------------------------------|
| `Mod+Shift+w`              | `nm-connection-editor` (full GUI)                 |
| `Mod+n`                    | `nmtui` in alacritty (TUI fallback)               |
| `XF86WLAN` (Fn+F8 ThinkPad)| `rfkill toggle wifi` (airplane-mode key)          |

The polybar `wlan` module to the right of the bar shows signal-strength
icons + SSID; left-click on it opens the same connection editor. The
`nm-applet` system-tray icon also offers a quick connect menu.

## Customising

The config is heavily commented. Common tweaks:

```bash
# Change Mod key (default = Mod4 / Super). Use Mod1 for Alt.
set $mod Mod4

# Change gaps (thin = 5, no gaps = 0)
gaps inner 5
gaps outer 2

# Add a new app shortcut.  Pick a key that isn't already bound — `Mod+m`
# (mute), `Mod+e` (Thunar), `Mod+b` (browser), `Mod+n` (nmtui),
# `Mod+Shift+w` (nm-connection-editor), `Mod+F8/9/10` (media), and
# `Mod+F11/12` (volume) are all taken.  `Mod+y` and `Mod+u` are free.
bindsym $mod+y exec spotify
```

After saving, hit `Mod+Shift+c` to reload.

## Window assignments

Force specific apps to a workspace by adding rules to the config:

```bash
assign [class="firefox-esr"] $ws2     # `firefox-esr` is the WM_CLASS Debian sets
assign [class="Slack"]     $ws9
for_window [class="Pavucontrol"] floating enable
```

To find the `class` of a running window: `xprop` → click the window → look for
`WM_CLASS`.
